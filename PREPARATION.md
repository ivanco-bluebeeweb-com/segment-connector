# Segment Connector — Preparation

**Category:** C36. Customer Data Platform (CDP)  
**Vendor URL:** https://segment.com  
**Preparation status:** Specification & Architecture Validated  
**API Documentation Reference:** Vendor Primary API Standard

## 1. Product passport
Коннектор **Segment** интегрирует платформу Imperal Cloud с официальным API сервиса для автоматизации задач в категории **C36. Customer Data Platform (CDP)**. Он предоставляет безопасный интерфейс к проверенным операциям вендора без использования синтетических шаблонов.

## 2. Человеческая проблема
Когда **Data-инженер** сталкивается с задачей: **централизация клиентских данных, управление источниками событий, маппингами и доставкой в назначения**, возникает необходимость ручного переключения между интерфейсами, что замедляет работу и увеличивает риск операционных ошибок. Коннектор Segment переносит ключевые сценарии управления прямо в экосистему Imperal.

## 3. Роли и права доступа
- **Data-инженер, маркетолог-аналитик, архитектор данных**: основные пользователи, управляющие бизнес-процессами.
- **Владелец рабочей зоны / Администратор**: отвечает за подключение коннектора и выдачу доступов.
- **Оператор Imperal**: выполняет действия только в рамках полномочий, разрешенных API-ключом вендора.

## 4. Первичный сценарий и границы
Основной сценарий: `создание источника данных -> подключение аналитического назначения -> валидация событий по плану трекинга`.

**Границы применимости:**
- Коннектор не хранит мастер-пароли и учетные данные третьих сторон.
- Любые необратимые или тарифицируемые операции требуют подтверждения.
- Соблюдаются лимиты запросов (rate limits) сервиса Segment.
